# TypeRacer Pro ⚡

A minimal, high-performance typing test engine with real-time WPM graphing, error reconciliation, mechanical soundpacks, and dark themes.

---

### 📌 GitHub Description
> A minimal, fast typing test platform with live WPM graphing, error reconciliation, mechanical switch audio, and dark themes. Built with React 19, TypeScript & Tailwind CSS.

---

## ✨ Features

- **Real-Time Analytics**: Zero-latency live WPM, raw WPM, accuracy, and interactive Recharts progression graphs.
- **True Error Reconciliation**: Edited mistakes via Backspace or word-click immediately clear errors and accuracy penalties.
- **Dark Theme Engine**: 8 curated dark themes with reactive CSS variables and dynamic SVG favicon.
- **Synthesized Audio**: Web Audio API soundpacks (Clicky, Thock, Tactile, Typewriter).
- **Test Modes**: Time (15s–120s), Words (10–100), Quotes, and Zen mode.
- **Mobile Ready**: Optimized virtual keyboard handling and responsive layout.

---

## 🛠️ Tech Stack

- **React 19** • **TypeScript** • **Vite** • **Tailwind CSS** • **Recharts** • **Web Audio API**

---

## 🚀 Quickstart

```bash
# Clone
git clone https://github.com/your-username/typeracer-pro.git
cd typeracer-pro

# Install & Run
npm install
npm run dev
```

Build for production:
```bash
npm run build
```

## ⌨️ Shortcuts

| Key | Action |
| --- | --- |
| `Tab` | Quick restart test |
| `Esc` | Reset current test |
| `Space` | Submit word |
| `Backspace` | Erase character / step back to previous word |
| `Ctrl / Alt + Backspace` | Delete entire current word |
